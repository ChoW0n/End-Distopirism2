# UI 제작 요청 (SPEC-007 §9.4·§9.5)

게임 UI 는 1920×1080 기준 화면 안에만 둔다. 버튼·틀·아이콘 그림은 여기서 요청한다.
그림이 오기 전까지 코드가 단색 임시 도형을 그린다.

## 보내는 순서

1. **U2 카드 틀** — 화면에서 가장 많이 보인다. 이걸로 톤을 먼저 승인받는다
2. U1 주 버튼 → U3 작은 버튼 (U2 승인본을 톤 참조로)
3. U4 아이콘 12종 (한 번에 한 개)
4. U5 적 선언 표지 · U6 아군 칸 판
5. U7 띠 재질

한 요청 = 한 요소의 한 상태 = 파일 1개. 결과는 각 yaml 의 `delivery`·`verification` 에 적는다.
이미지는 커밋하지 않는다 (SPEC-002 §9). 요청서와 검수 기록만 커밋한다.
