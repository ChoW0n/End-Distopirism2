# UI 제작 요청 (SPEC-004 §13 · SPEC-007 §9.4)

게임 UI 는 1920×1080 기준 화면 안에만 둔다 (iPhone 15 가로 2556×1179 는 높이를 맞춰 가운데 1920 안에 둔다).
버튼·틀·아이콘 그림은 여기서 요청한다. 그림이 오기 전까지 코드가 단색 임시 도형을 그린다.
요소 전부와 크기·자리는 `docs/SPEC-004-UI계층.md` §13.3 표 (U1~U19). 원본은 기준 크기의 **2배**로 받는다.

## 보내는 순서

1. **U2 카드 틀** — 화면에서 가장 많이 보인다. 이걸로 톤을 먼저 승인받는다
2. U1 주 버튼 → U3 작은 버튼 → U18 가로 버튼 (U2 승인본을 톤 참조로)
3. U4 아이콘 16종 (한 번에 한 개)
4. 무대 위: U9 이름표 → U11 발밑 바 틀 → U12 궁극기 칸 → U5 노림 표지 → U13 선택 고리 → U10 상태이상 아이콘
5. U6 아군 칸 · U16 궁극기 카드 틀 · U15 머리 위 카드 앞·뒤
6. U14 합 결과 판 · U19 결과 배너 · U8 턴 판 (원작 그림 재사용 검토 먼저)
7. U7 띠 재질 · U17 겹창 판

한 요청 = 한 요소의 한 상태 = 파일 1개. 결과는 각 yaml 의 `delivery`·`verification` 에 적는다.
이미지는 커밋하지 않는다 (SPEC-002 §9). 요청서와 검수 기록만 커밋한다.
