# SPEC-001 · 전투 시스템

상태: **확정 v1.0** (TBD 전건 결정, 구현 착수 가능) / 작성 2026-09-14 / 근거: 2024 기획서 + 데이터 시트 + `스킬 상세 설명 문서.txt` + 코드 `c900a71`

> 이 문서가 전투 규칙의 **단일 기준(source of truth)** 이다.
> 기획서와 코드가 다르면 이 문서가 이긴다. 코드를 고치는 근거도 여기서 나온다.

## 1. 범위

전투 씬 1회분. 덱 빌딩·스테이지 선택·성장은 별도 스펙.

---

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 합(클래시) | 양측이 카드를 내고 피해량을 겨루는 1회 교환 |
| 턴 | 모든 아군이 카드/타겟을 정하고 전원의 합이 끝날 때까지 |
| 코인 | 합에서 굴리는 확률 자원. 합 패배 시 1개 차감, 턴마다 회복 |
| 정신력 | 코인 성공 확률을 결정하는 0~100 수치 |
| 교착 | 양측 피해량이 완전히 같은 상태 |

## 3. 턴 진행

```
턴 시작
 └ 모든 캐릭터 코인 회복 (maxCoin + nextTurnCoinModifier)
 └ 지속 상태이상 판정 (출혈 등)
 └ 모든 적이 각자 아군 1명을 타겟으로 고른다 (가중 랜덤, §13.6)   ← D-7
아군 입력 단계
 └ 아군 선택 → 타겟 선택 → 카드 선택  (아군 수만큼 반복)
매칭 판정                                                      ← D-7
 ├ 아군A→적X 이고 적X→아군A   → 합(클래시)
 ├ 아군A→적X 인데 적X→아군B   → A는 X에게 일방, X는 B에게 일방
 └ 아무도 안 겨눈 적           → 자기 타겟에게 일방 공격
전투 실행 단계
 ├ 합: 매칭쌍마다 순서대로
 │    ├ 양측 코인 굴리기
 │    ├ 피해량 산출
 │    ├ 비교
 │    │   ├ 피해량 다름 → 합 결과 처리 → 패자 코인 -1 → 코인 남으면 재대결
 │    │   ├ 피해량 같음 → 교착 처리
 │    │   └ 양측 코인 0   → 승자가 잔여 피해 적용
 │    └ 전투 종료 조건 확인
 └ 일방 공격: §4.7
턴 종료
```

**실행 순서**: 아군 지시를 받은 순서대로 먼저 처리하고(합이든 일방이든), 그 다음 적의 일방 공격을 적 순서대로 처리한다.
앞선 교전에서 한쪽이 쓰러지면 그 캐릭터가 낀 남은 교전은 건너뛴다.

**출혈 판정 위치**: 턴 시작이다. D-7 이후로는 한 캐릭터가 한 턴에 여러 교전에 낄 수 있어
(합 1건 + 일방 피격 2건) 교전마다 판정하면 출혈이 중복으로 들어간다. 캐릭터당 턴 1회로 고정한다.

## 4. 수치 규칙

### 4.1 코인 성공 확률 **[FIX-01]**

```
성공확률 = 0.6 × (정신력 / 100)
코인 1개씩 독립 시행, 성공 개수 = successCount
```

- 정신력 100 → 60%
- 정신력 50 → 30%
- 정신력 0 → 0%

> **현재 코드는 이 규칙을 지키지 않는다.** `0.6 × 100 = 60`을 확률로 써서 `Random.value(0~1) < 60`이 항상 참 → 코인 100% 성공.
> 정신력 시스템 전체가 지금 무의미하다. 이 스펙의 최우선 수정 항목.

### 4.2 피해량

```
피해량 = 카드최소피해 + (successCount × 카드코인위력) + 레벨차보너스
```

### 4.3 레벨차 보너스 **[FIX-02]**

```
조건: 공격자.공격레벨 > 방어자.방어레벨 + 4
보너스 = floor((공격자.공격레벨 - 방어자.방어레벨) / 4)
조건 미충족 시 보너스 = 0   ← 매 합마다 반드시 초기화
```

> 현재 코드는 **자기 자신의 방어레벨**을 뺀다. 조건은 상대 기준, 계산은 자기 기준으로 섞여 있다.
> 또 조건 미충족 시 0으로 안 돌려서 이전 턴 값이 남는다.

### 4.4 합 판정 **[FIX-03]**

| 상황 | 결과 |
|---|---|
| 내 피해 > 상대 피해 | 내 승리. 상대 코인 -1, 나 정신력 +2 (상한 100) |
| 내 피해 < 상대 피해 | 상대 승리. 내 코인 -1, 상대 정신력 +2 |
| 내 피해 == 상대 피해 | **교착** (승/패 아님) |
| 패자 코인이 0 | 합 종료, 승자가 잔여 피해를 패자에게 적용 |

> 현재 코드는 `>` / `else` 2분기라 동점이 적 승리로 표시된다. 3분기여야 한다.

### 4.5 교착

- 발생 시 재대결. 코인은 차감하지 않는다
- **3회 누적** 시 합 종료, 양측 정신력 -10, 교착 카운터 0으로 리셋
- 교착 카운터는 매칭쌍 단위 (현재 코드는 `BattleManager.draw` 전역 필드 — 쌍별로 분리해야 함)

### 4.6 정신력

| 사건 | 변동 |
|---|---|
| 합 승리 | +2 (상한 100) |
| 교착 3회 | -10 |
| 카드 「마무리」 합 패배 | -5% (현재치 기준 비율) |
| 혼란 상태 | 계산 시 -20 (실제 수치를 깎지 않음) |
| 20 미만 | 혼란 자동 발생 |
| **턴 종료** | **+4 (단 30까지만)** — 하강 나선 차단용 [D-5] |

### 4.7 일방 공격 **[D-7]**

서로 겨누지 않아 합이 성립하지 않을 때, 공격자는 겨룰 상대 없이 그대로 때린다.

| 항목 | 처리 |
|---|---|
| 코인 | 굴린다. 피해량 산출에 필요하다 |
| 승패 | **자동 승리로 간주** (겨룰 상대가 없음) |
| 피해 | 그대로 적용 |
| 카드 효과 | 「합 승리 시」 효과 **발동** |
| 코인 차감 | **없음** (`oneSidedConsumesCoin: false`) |
| 정신력 +2 | **없음** (`oneSidedGivesMentality: false`) |
| 교착 | 발생하지 않음 |

정신력 +2를 주지 않는 게 핵심이다. 회복은 **겨뤄서 이겼을 때만** 나온다.
그래야 "합을 걸어라"는 압력이 생기고, 일방 공격으로 안전하게 때리는 플레이가 정신력 관리를 대체하지 않는다.

맞는 쪽의 카드는 관여하지 않는다. 그 캐릭터는 자기 타겟을 때리는 중이라
**「방어 태세」도 일방 공격을 막지 못한다.** 막을 수 있으면 §13.7 의 가중치 0 규칙과 모순된다.

승패 분기는 `didWin` 기준이다. 일방 공격도 승리이므로 승리 효과가 그대로 나온다.
`wasClash` 조건이 따로 걸리는 것은 정신력 회복과 코인 차감 두 가지뿐이다.

## 8. 밸런싱 원칙 (판단 기준)

1. **카드 1장의 피해 변동폭(최대÷최소)은 3.0배를 넘지 않는다.** 기획서의 "체급의 10~15%"는 정의 불명 + 달성 불가로 폐기하고 변동폭 기준으로 대체 (§12.2, §12.8)
2. 운(코인)보다 스탯(공/방 레벨)의 영향이 커야 한다
3. 공격레벨이 방어레벨보다 높아도 극단적 피해가 나오면 안 된다
4. 정신력 100 유지가 쉬우면 안 된다 — 유지 난이도가 전략의 축

### 12.1 코인 기여율 실측 (정신력 100 기준)

`기대 코인 피해 ÷ 총 기대 피해`. 레벨차 보너스·승패 후 효과는 제외.

| 무모한 일격 | 5.4 / **100%** | 9.0 / **100%** | 3.6 / **100%** |
| 연속 찌르기 | 6.6 / 54.5% | 9.0 / 66.7% | 5.4 / 44.4% |

| 방어 태세 | 0 / — | 0 / — | 0 / — |
| 사기 진작 | 4.6 / 78.3% | 7.0 / 85.7% | 3.4 / 70.6% |

| 화염 공격 | 10.0 / **90.0%** | 16.0 / **93.8%** | 7.0 / **85.7%** |

**전 카드가 원칙 1 위반.** 특히 무모한 일격·강력한 한 방·화염 공격은 사실상 코인이 피해량을 결정한다.

### 12.2 10~15% 목표는 달성 불가 — 목표치 자체를 바꿔야 한다

기여율을 목표까지 낮추려면 `최소피해`가 `코인위력`의 몇 배여야 하는지:

| 목표 기여율 | 조력자(3코인) | 메인(5코인) | 지하경찰(2코인) |
|---|---|---|---|
| 15% | ×10.2 | **×17.0** | ×6.8 |
| 30% | ×4.2 | ×7.0 | ×2.8 |
| 40% | ×2.7 | ×4.5 | ×1.8 |

15%를 맞추려면 메인 캐릭터 기준 `최소피해 = 코인위력 × 17`이다. 코인위력 1이면 최소피해 17 —
**카드가 사실상 결정론이 되고 코인 시스템이 장식이 된다.**

GPT가 제시한 예시 `1+6×코인 → 7+2×코인`도 실제로는 25~46%까지만 내려간다:

| | 조력자 | 메인 | 지하경찰 |
|---|---|---|---|
| 기존 `1+6×` | 11.8 / 91.5% | 19.0 / 94.7% | 8.2 / 87.8% |
| 제안 `7+2×` | 10.6 / 34.0% | 13.0 / 46.2% | 9.4 / 25.5% |

→ **결론: 기획서의 10~15%를 그대로 목표로 쓸 수 없다.** 현실적 목표는 **25~35%** 선.
이 수치를 확정하는 것이 카드 재배분보다 먼저다.

### 12.3 확률 수정 방향

- 확률 상수 인상 — **비추천.** 피해는 복구되지만 운 의존도가 그대로다
- 체력 하향 — **차선.** 전투는 짧아지나 코인 편차가 바로 생사로 직결
- **카드 수치 재배분 — 채택.** `최소피해 ↑ / 코인위력 ↓`
- **확률 0.6은 유지한다.**

### 12.4 정신력 하강 나선 — 확인됨, 슬로프가 아니라 절벽

| 정신력 | 혼란 | 실효 | 성공률 |
|---|---|---|---|
| 100 | X | 100 | 60% |
| 40 | X | 40 | 24% |
| 20 | X | 20 | 12% |
| **19** | **O** | **0** | **0%** |
| 10 | O | 0 | 0% |

혼란이 `-20` 고정이라 **정신력 20 미만은 예외 없이 성공률 0%다.** 12%에서 0%로 한 칸에 떨어진다.
회복 수단은 합 승리 +2뿐인데 성공률 0%로는 합을 이길 수 없다 → **자력 탈출 불가.**

**수정안 (GPT 제안, 채택 권장):** 턴 종료 시 정신력 `+3~5`, 단 **30까지만** 자연 회복.
붕괴의 위험성은 유지하면서 영구 패배 나선만 차단한다.

### 12.5 방어 태세 — 지배 전략 확인

`합 패배해도 피해 없음`이 코인 소진 후 최종 피해까지 막으면 계속 내기만 해도 죽지 않는다.
다만 피해 0·코인 0이라 상대도 죽일 수 없어 **승리 전략이 아니라 무한 교착**이 된다. 그래도 결함이다.

수정안 (택1, 미확정):
- (A) `합 패배 시 최종 피해 50% 감소` — GPT 제안. 단순하지만 카드 정체성이 사라짐
- (B) 완전 면역 유지 + **턴당 1회** 또는 **덱 1장** 제한 — 카드 정체성 보존
→ **(B) 권장.** 이 카드의 존재 이유가 "한 번은 확실히 버틴다"인데 (A)는 그냥 평범한 경감 카드가 된다.

### 12.6 적 AI — 완전 랜덤은 exploitable

플레이어는 카드 상성·상태이상을 의도적으로 쓰는데 AI가 무작위면 장기적으로 반드시 뚫린다.
코인 고점으로 우연히 강할 수는 있으나 그건 전략적 위협이 아니라 난수 위협이다.

**수정안:** 완전 랜덤 → **유효 카드 필터링 후 가중 랜덤.** 반영 인자는 현재 HP / 정신력 / 상대 카드 예상 피해 3개면 충분.

### 12.8 확정 수치 — 카드 재배분 [D-2]

**기준: 변동폭(최대÷최소) ≤ 3.0배.** 기여율 %가 아니라 이걸 쓰는 이유는, 불쾌함이 평균 기여율이 아니라
"같은 카드를 냈는데 결과가 뒤집히는 것"에서 나오기 때문이다. 기존 「강력한 한 방」은 1~31, **31배 변동**이었다.

| 카드 | 신규 | 메인 기대피해 (구→신) | 변동폭 (구→신) |
|---|---|---|---|
| 마무리 | `9 + 2×코인` | 15.0 → 15.0 | 7.7배 → **2.11배** |
| 무모한 일격 | `6 + 1×코인` | 9.0 → 9.0 | ∞ → **1.83배** |
| 연속 찌르기 | `7 + 1×코인` | 9.0 → 10.0 | 4.3배 → **1.71배** |
| 강력한 한 방 | `8 + 3×코인` | 19.0 → 17.0 | 31.0배 → **2.88배** |
| 독 바르기 | `9 + 1×코인` | 13.0 → 12.0 | 4.8배 → **1.56배** |
| 방어 태세 | `0 + 0×코인` | 0 → 0 | — |
| 사기 진작 | `5 + 1×코인` | 7.0 → 8.0 | 11.0배 → **2.00배** |
| 파열 | `6 + 2×코인` | 10.0 → 12.0 | 16.0배 → **2.67배** |
| 화염 공격 | `9 + 2×코인` | 16.0 → 15.0 | 26.0배 → **2.11배** |

**전 카드 최대 변동폭 2.88배** (기존 ∞). 코인이 결과를 뒤집지 못하고 기댓값을 흔드는 선에서 멈춘다.

카드 원형(archetype) 구분:
- **안정** (1.5~1.9배): 무모한 일격, 연속 찌르기, 독 바르기 — 계산이 서는 카드
- **표준** (2.0~2.2배): 마무리, 사기 진작, 화염 공격
- **도박** (2.6~2.9배): 강력한 한 방, 파열 — 그만큼 기댓값이 높다

**부작용 (감수하고 확정):** 고정피해를 올리면 코인이 적은 캐릭터가 상대적으로 이득을 본다.
캐릭터별 총 기대피해는 조력자 +28%, 메인 ±0%, 지하경찰 +57%.
지하경찰은 체력 230 / 공격레벨 35의 글래스캐논이라 컨셉에 부합하므로 그대로 둔다.
전투가 짧다고 느껴지면 **체력을 올리지 말고 `coinBaseProbability`를 0.6으로 고정한 채 카드 `baseDamage`에 전역 계수를 곱해라.** 변동폭 비율이 보존된다.

> **주의:** 현재 실제 플레이 감각(코인 100% 성공) 대비로는 피해가 크게 **줄어든다.**
> 「강력한 한 방」 기준 31 → 17. 전투는 길어지는 방향이다. 이게 정상이고, 기존 감각이 버그였다.

### 12.7 작업 우선순위 (검토 반영)

## 11. 검증 기준

이 스펙을 구현했다고 말하려면 아래가 **실행 결과로** 확인돼야 한다.

- 정신력 100/50/0 각각 1000회 코인 시행 → 성공률 60%/30%/0% ±3%
- 레벨차 보너스: 공32 vs 방12 → 5, 공29 vs 방5 → 6, 공29 vs 방26 → 0
- 동점 입력 → 교착 처리, 3회 누적 시 양측 정신력 -10
- 상태이상 4종이 명시된 타이밍에 발동
- 카드 9종 효과가 UI 설명문과 일치
- 적 AI가 정신력·위협도에 따라 카드 선택 분포를 바꾼다 (§13)
- 같은 난수 씨앗이면 적 AI가 항상 같은 선택을 한다
- 3 vs 3에서 아군 셋이 적 하나에 몰리면 → 합 1건 + 아군이 받는 일방 공격 2건
- 아군 셋이 각자 다른 적을 겨누고 적도 같은 상대를 겨누면 → 합 3건, 일방 공격 0건
- 일방 공격으로 이겨도 정신력이 오르지 않고, 맞는 쪽 코인도 줄지 않는다
- HP 100%인 적은 방어 태세를 한 번도 내지 않는다 (위협도 < 0.15)
- HP가 낮고 큰 피해가 예상되는 적은 방어 태세 빈도가 뚜렷하게 오른다

## 13. 적 AI 규칙 [D-6 / D-7.2 / D-8]

§12.6 의 "유효 카드 필터링 후 가중 랜덤"을 구현 가능한 수준으로 확정한 것.
**적에게만 적용한다.** 아군의 타겟·카드 선택은 플레이어 입력이다.

적은 한 턴에 두 번 판단한다. **타겟은 턴 시작에**(§13.6), **카드는 매칭 판정 뒤에**(§13.1) 고른다.
순서가 이렇게 갈리는 이유는 §13.8 에 적었다.

### 13.1 카드 선택 절차

```
후보 = 적의 덱에 있는 카드 전부
 └ 카드마다 가중치 계산
 │   ├ 방어형(원형 유틸)  → §13.7 의 위협도 단계 가중치로 시작
 │   └ 그 외             → 1.0 으로 시작
 └ 원형 계수(§13.2)와 중복 감점(§13.3)을 곱한다
 └ 가중치에 비례해 무작위로 1장 추첨
```

가중치 합이 0이면 균등 랜덤으로 되돌린다. 덱이 비어 있으면 오류다.

### 13.2 정신력 계수

`실효정신력 <= mentalityDangerThreshold` 이면 카드 원형별로 `mentalityDangerArchetypeWeight` 를 곱한다.
정신력이 낮으면 코인이 거의 붙지 않으므로 고정피해 비중이 큰 `안정` 이 유리하고 `도박` 은 불리하다.

> 체력은 카드 선택에 직접 들어가지 않는다. `위협도 = 예상피해 / 현재HP` 의 분모라
> §13.7 을 통해 반영된다. D-8 이 §12.6 의 인자 1·3 을 위협도 하나로 합친 결과다.

### 13.3 중복 상태이상 감점

카드의 승리 효과가 **중첩 불가** 상태이상을 거는 것인데 상대에게 이미 그게 걸려 있으면
가중치에 `redundantStatusPenalty` 를 곱한다. 이것이 §12.6 의 "유효 카드 필터링"에 해당한다.
후보에서 완전히 빼지 않는 이유는 그 카드에도 고정 피해가 있어 무가치하지 않기 때문이다.

### 13.4 확정 수치

데이터는 `battle-data.json` 이 기준이다.
일방 공격 상수 2개는 `rules`, AI 가중치는 `enemyAi` 블록에 있다.

| 블록 | 키 | 값 | 뜻 |
|---|---|---|---|
| `rules` | `oneSidedGivesMentality` | false | 일방 공격 승리로는 정신력이 오르지 않는다 |
| `rules` | `oneSidedConsumesCoin` | false | 일방 공격으로 맞아도 코인을 잃지 않는다 |
| `enemyAi` | `mentalityDangerThreshold` | 40 | 실효 정신력 40 이하면 위험 |
| `enemyAi` | `mentalityDangerArchetypeWeight` | 안정 2.0 / 표준 1.2 / 도박 0.4 / 유틸 1.0 | 원형별 배수 |
| `enemyAi` | `redundantStatusPenalty` | 0.2 | 이미 걸린 중첩 불가 상태이상을 또 거는 카드의 배수 |
| `enemyAi` | `aiTargetLowHpBias` | 1.0 | 빈사 아군에 몰리는 정도 (§13.6) |
| `enemyAi` | `aiTargetDuplicatePenalty` | 0.5 | 이미 다른 적이 고른 아군의 배수 |
| `enemyAi` | `aiGuardThreatThresholds` | [0.15, 0.30, 0.50] | 방어 태세 위협도 구간 경계 |
| `enemyAi` | `aiGuardWeights` | [0, 0.5, 2.0, 4.0] | 구간별 방어 태세 가중치 |

> **결정 문서와의 차이**: 결정 문서는 6개 상수를 전부 `rules` 에 넣으라고 했으나,
> `ai*` 4개는 이미 `enemyAi` 블록에 있는 AI 가중치와 같은 성격이라 그쪽으로 옮겼다.
> 키 이름은 대조가 쉽도록 문서 그대로 뒀다. 일방 공격 2개는 AI 가 아니라 전투 규칙이라 `rules` 에 있다.
>
> D-8 이 대체해서 **삭제한 상수**: `hpDangerRatio`, `hpDangerDefensiveBonus`, `threatRatio`, `threatDefensiveBonus`.
> 방어 태세 가중치를 §13.7 이 통째로 정하므로 곱해질 자리가 없어졌다.

### 13.6 타겟 선택 **[D-7.2]**

턴 시작에 적이 각자 아군 1명을 고른다.

```
가중치 = 1.0
       × (1 + aiTargetLowHpBias × (1 - 아군HP비율))   // HP 100% → ×1.0, HP 20% → ×1.8
       × (이미 다른 적이 고른 아군이면 aiTargetDuplicatePenalty)
```

선택 순서는 적 인덱스 순. 앞선 적의 선택이 뒤 적의 가중치에 반영된다.
쓰러진 아군은 후보에서 뺀다.

### 13.7 방어 태세 가중치 **[D-8]**

```
위협도 = 상대 예상 피해 / 내 현재 HP
상대 예상 피해 = 상대카드최소 + (상대maxCoin × coinBaseProbability × 상대카드코인위력)
```

합 상대가 이미 카드를 고른 상태면 **그 카드**로 계산하고, 아직이면 **상대 덱의 평균**으로 대체한다.
레벨차 보너스는 넣지 않는다 — 결정 문서의 식을 그대로 쓴다.

| 위협도 | 방어 태세 가중치 |
|---|---|
| < 0.15 | **0** — 후보에서 제외 |
| 0.15 ~ 0.30 | 0.5 |
| 0.30 ~ 0.50 | 2.0 |
| ≥ 0.50 | 4.0 |

**일방 공격이 예상되는 턴**(= 이 적을 아무도 안 겨눔)에는 가중치 **0**이다.
겨룰 상대가 없으면 방어할 게 없다.

방어 태세는 덱 1장 제한(D-4)이라 애초에 손에 잡힐 확률이 낮다. 위 가중치는 그 위에 곱해진다.

### 13.8 판단 시점이 갈리는 이유

- **타겟은 턴 시작.** 아군 입력을 보고 적이 타겟을 정하면 아군이 항상 합을 강제할 수 있다
- **카드는 매칭 판정 뒤.** §13.7 이 "합인지 일방인지"와 "상대가 낸 카드"를 알아야 계산된다.
  타겟이 이미 고정된 뒤라 아군이 이를 역이용할 수 없다
