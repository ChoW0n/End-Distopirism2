# SPEC-001 v3.0 개정 · 코인 폐지, 카드 앞/뒤 [D-23]

상태: **확정 v3.0** / 작성 2026-09-28 / 대체 대상: SPEC-001 v1.0 §4.1·§4.2·§4.4·§4.5·§4.7 의 코인 부분, v2.0 의 코인 수치

> 사용자 결정 (2026-09-28):
> - 스킬은 나중에 **카드**로 디자인한다. **앞면 / 뒷면**을 나누고, 앞면은 스킬 그림 그대로, 뒷면은 회색 필터로 처리한다
> - 카드마다 **앞 위력 / 뒷 위력**이 따로 있다
> - **코인은 시스템에서 사라진다.** 캐릭터의 **정신력과 체력에 비례해** 앞면이 나올 확률이 달라진다
> - 연출: 서로 달려가면서 화면이 느려지고 → 카드가 머리 위에서 돌다가 "띵!" 하고 앞/뒤가 드러나고 → 위력을 비교해 **열세인 쪽이 맞는다** (SPEC-005 §11)
> - 이렇게 하면 겨루기용 일반 공격 스프라이트 없이 **스킬 스프라이트만** 만들면 된다
> - 지금은 카드 그림 대신 **임시 도형**을 붙인다
>
> 세부 수치 (같은 날 질문 답):
> - 앞면 확률은 **30~80%** 사이에서 정신력·체력으로 움직이되, **카드의 효과와 위력(밸류)을 고려해 밸런싱**한다
> - 진 쪽이 맞는 양은 **이긴 쪽 위력 + 공방 레벨차 보너스**
> - 위력이 같으면 **다시 뒤집는다**
> - 기존 카드의 앞/뒤 위력은 **앞 = 옛 최대(기본 + 코인당 × 코인 수), 뒤 = 옛 기본**
>
> 바뀌지 않는 것: 턴 진행 순서, 매칭(D-7), 레벨차 보너스 식(§4.3), 정신력 증감 수치(D-21), 상태이상, 속성·궁극기, 카드 효과 타이밍

---

## 1. 카드 앞/뒤

- 카드마다 `frontPower`(앞 위력)·`backPower`(뒷 위력)를 가진다. 앞이 뒤보다 크거나 같다
- 교전마다 카드를 한 번 뒤집어 **앞 또는 뒤**가 나온다. 드러난 면의 위력이 그 교전의 위력이다
- 코인·코인 수(`maxCoin`)·코인 차감·코인 회복·재대결(코인이 떨어질 때까지 반복)은 **모두 없어진다**

## 2. 앞면 확률

```
상태 = 정신력 가중 × (실효 정신력 / 정신력 상한) + 체력 가중 × (현재 체력 / 최대 체력)
앞면 확률 = 카드 최소 + (카드 최대 − 카드 최소) × 상태
```

- 가중은 정신력 0.5 · 체력 0.5 (`rules.cardFlip`)
- 실효 정신력은 지금처럼 혼란이면 `confusionPenalty` 만큼 낮춘다
- 카드마다 `frontChance: [최소, 최대]` 를 가진다. **30% ~ 80% 밖으로 나가지 않는다** (`rules.cardFlip.chanceFloor`·`chanceCeiling`)
- **밸런싱 규칙 (초기값)** — 효과와 밸류가 큰 카드는 앞면이 덜 나온다
  - 기본 30 ~ 80%
  - 앞/뒤 위력 비가 **3.0 배 이상**이면 최대 −5%p
  - **효과**가 붙어 있으면 최대 −5%p
  - 시뮬레이터로 다시 맞춘다. 데이터에 적힌 값이 기준이다

## 3. 겨루기 (합)

1. 양쪽이 카드를 뒤집는다 (`cardFlipped` 두 개)
2. 드러난 **위력**을 비교한다
   - 다르면 위력이 **큰 쪽이 이긴다**. 진 쪽이 맞는다
   - 같으면 **교착 — 다시 뒤집는다.** 교착이 `deadlockLimit`(3) 번 쌓이면 피해 없이 끝나고 둘 다 정신력 `mentalityOnDeadlock`(−10)
3. 이긴 쪽 정신력 `mentalityOnClashWin`(+2), 진 쪽 `mentalityOnClashLose`(−5). 한 합에 한 번이다 (라운드가 여러 번 돌던 코인 방식과 다르다)
4. 피해 = **이긴 쪽 위력 + 레벨차 보너스**(이긴 쪽 공격레벨 vs 진 쪽 실효 방어레벨, §4.3) → 독 보정 → 카드 효과(§6 타이밍 그대로)
5. 속성은 이긴 쪽 카드에 한 번 오른다 (v2.0 §2.1 그대로)

## 4. 일방 공격

- 공격자만 카드를 뒤집는다. 드러난 위력 + 레벨차 보너스가 피해다
- 정신력은 지금처럼 기본적으로 움직이지 않는다 (`oneSidedGivesMentality`)

## 5. 데이터

| 자리 | 바뀜 |
|---|---|
| `rules` | `coinBaseProbability`·`oneSidedConsumesCoin` 삭제. `cardFlip: { mentalityWeight, hpWeight, chanceFloor, chanceCeiling }` 추가 |
| `characters[]` | `maxCoin` 삭제 |
| `skills[]` | `baseDamage`·`coinPower` → `frontPower`·`backPower`·`frontChance` |
| 효과 | 코인에 기대던 효과 3종(`selfHpCost` 코인당 피해, `nextTurnCoin`, `atkBonusPerCoin`) 삭제. 지금 데이터에서 쓰는 카드가 없다 |
| 상태이상 | 혼란의 시점 `onCoinRoll` → `onCardFlip` |

## 6. 이벤트

| 없어짐 | 새로 | 바뀜 |
|---|---|---|
| `coinRestored` · `coinRolled` · `coinLost` | `cardFlipped { combatantId, skillId, face: 'front'∣'back', power, chance }` | `damageCalculated` 의 `successCount` → `power`(드러난 위력) |

`clashRoundWin` 은 뒤집기 한 번의 승패, `deadlock` 은 다시 뒤집기다. 합 하나에 `clashRoundWin` 은 많아야 한 번 나온다.

## 8. 밸런싱 원칙 1 (변동폭) 을 다시 읽는다

- 카드 1장의 앞/뒤 위력 비는 **3.0 배를 넘지 않는다** (옛 "최대÷최소 ≤ 3.0" 과 같은 값)
