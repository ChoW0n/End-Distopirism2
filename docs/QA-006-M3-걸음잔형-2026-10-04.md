## 3. 발견·수정

- 맨손 공격도 기존 매니페스트의 `bladeTip`이 필수였다. 준비/타격 6장에 손끝·주먹 접점을 수동 지정했다. 후보 매니페스트 로드 실패는 오류로 표시한다.
- 렌더 대상이 빠져도 기존 경계 검사만으로는 통과할 수 있었다. QA 도구는 대진 2명, 모든 장의 판 생성, 후보 아트 ID를 먼저 검증한다.
- 전달 준비 중 빈 정렬 PNG 1건을 발견해 재생성했다. 정렬 출력은 임시 파일 저장→교체→재열기 검증으로 변경했고, HTML 묶음도 정렬 PNG 해시가 다르면 생성을 중단한다. 최종 파일은 UI·오프라인·실전 로드에서 모두 확인했다.
- 초기 막기 그림의 여분 다리는 재제작했다. 피격의 얼굴 방향과 짓누르기 타격 손 모양도 수정했다. 프레임마다 천 주름·작은 결정 형태 차이가 조금 있어, 미술 채택 시 함께 판단한다.

## 4. 재현·반입

1. 소스 가지 `claude/trusting-keller-2qeupr`의 최신 코드를 받는다. 기존 카일·공용 이미지와 소리는 기존 검토 묶음에서 복원한다. 오래된 검토 가지의 코드·JSON으로 최신 소스를 덮지 않는다.
2. ZIP의 `assets/remnantWalker/source/`와 `norm/`을 소스의 같은 경로에 복사한다. JSON은 해당 소스 버전과 일치하는 묶음이다.
3. `python3 scripts/remnant_assets.py`로 정렬을 재생성할 수 있다(Pillow 필요).
4. `npm ci && npm run web` 후 저장소 루트에서 HTTP 서버를 연다. 검토 주소 또는 전투 후보 주소에 접속한다.
5. `python3 scripts/qa_m3_ui.py --output /tmp/m3-ui --standalone /절대경로/End-Distopirism-M3.html`, `python3 scripts/qa_m2.py --cases watch:2 --art-preview remnantWalker --output /tmp/m3-battle`로 재검증한다(기본 서버 127.0.0.1:8000, Playwright 필요).

정렬 메타데이터는 `assets/remnantWalker/`, 검사 요약은 `docs/qa/m3/`, 원시 렌더 기록과 캡처는 전달 ZIP의 `evidence/`에 있다. 이미지·소리는 소스 가지에 커밋하지 않는다. `review-2026-10-03`도 이번 작업에서 갱신하지 않았다.
