## 자동 검사와 증거

- 타입 검사·웹 빌드 통과. **553 통과, 0 실패, 0 건너뜀**. 검토 가지의 이미지 399개를 복원해 M1에서 빠졌던 이미지 검사도 실행했다.
- 16:9·19.5:9·4:3의 타격 펀치·양방향·큰 밀려남·복귀를 실제 카메라 투영으로 검사하는 회귀 4건을 추가했다.
- `scripts/qa_m2.py`, `qa_m2_probe.mjs`, `qa_m2_capture.js`는 제품 코드를 바꾸지 않고 임시 검수 번들에 측정 참조를 넣는다. 이벤트 순서·도메인 결과는 그대로이며 캡처할 순간에만 연출 시계를 잠시 멈춘다.
- 시드 입력은 재시작할 때 적용된다. 모드만 바꾸면 기존 세션이 계속되는 점을 확인해 검수 도구가 재시작과 실제 생성 시드를 검증하게 했다. 시드 미적용 실행은 최종 집계에서 제외했다.
- 수정 전 시연과 중간 실패도 따로 보존했다. 최종 합격 결과와 섞지 않았다. 최종 전달 HTML에는 최종 원시 기록을 내려받는 링크가 들어 있다.
