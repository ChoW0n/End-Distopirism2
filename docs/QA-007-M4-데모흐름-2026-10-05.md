### 전투 결과와 검사 기대값 정정

직접 조작 모드에 실제 버튼 입력을 보낸 시드 1은 물금·이면·잔향을 번갈아 쓰고 9턴에 미명으로 승리했다. 자동 관전 시드 2·3은 각각 5턴 패배였다. 승리 후 재시작해 다음 패배까지 이어진 경로를 확인했다. 이 직접 입력 표본은 4~8턴 목표를 1턴 넘으므로 D1 통과로 표시하지 않는다.

기존 `qa_regression.py`는 시드 3에 현행 수치와 맞지 않는 `승리` 기대값을 갖고 있어 첫 실행에서 1건 실패했다. 수정 전 `1940932` HTML로 동일 입력을 재생해도 5턴 패배였고, `npm run sim -- --seed 3 --runs 1 --bot ai`도 `winner=enemy`, `turns=5`였다. `src/`·`assets/`·`docs/battle-data.json`은 기준 커밋과 차이가 없다. 제품 회귀가 아닌 오래된 기대값으로 확인해 정확한 결과인 `패배`로 수정했다. 최초 실패 기록도 보존한다.

## 4. 재현

기존 검토 가지에서 이미지·음향만 복원하고 최신 소스의 코드·JSON은 유지한다. M3 검수에는 runtime 묶음의 norm PNG도 같은 경로에 둔다. `npm ci && npm run web` 후 저장소 루트에서 HTTP 서버를 연다.

```bash
python3 scripts/qa_m4_flow.py --baseline-ref 1940932 --output /tmp/m4-flow
python3 scripts/qa_regression.py --suite smoke,modal,mobile --output /tmp/m4-regression
python3 scripts/qa_regression.py --suite battle --output /tmp/m4-battle
python3 scripts/qa_m3_ui.py --output /tmp/m3-restore --standalone /절대경로/End-Distopirism-M3.html
npm run typecheck
npm test
```

Python Playwright와 해당 Chromium, 한글 글꼴이 필요하다. 결과 JSON은 `docs/qa/m4/`, 이번 수정 전후 화면과 실행 로그는 `M4-QA-007-evidence.zip`으로 전달한다.
