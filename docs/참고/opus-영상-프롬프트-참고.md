## 우리와 이미 겹치는 것 (재확인)

SPEC-005 §17 로 이미 넣은 것: 히트스톱·화각 펀치·배경 누르기·섬광(0.28 ≤ 0.8)·상시 입자·흔들림 줄이기.

## 비어 있는 것 (제안 — 결정이 아니다)

1. **충전 단계**: SPEC-005 §10.1 은 결행 앞에 "시전 준비 장"(칼집에 넣은 채 끊을 준비)을 두지만, **입자가 빨려들고 음이 오르는 충전 연출은 스펙에 없다.** 후보로 올릴지 사용자에게 묻는다. 컷신 앞 긴장이 박진감의 큰 몫이다
2. **"계속 흔들지 않는다" 점검**: 타격 반응 남발 방지 — HANDOFF-001 §3.3 의 "무거운 타 판당 3~8회" 가 이 원칙의 수치
3. **완성 점검 캡처 4시점**: 충전·폭발·공개·정산마다 가림·과노출·잔여 흔들림을 본다 (`ed2-workflow` ⑦ 검증의 캡처에 포함)
4. **시연 소개 영상**: 에이전트가 직접 플레이·촬영·편집한 예고편 방식. 데모 마무리(HANDOFF-001 M4~M6)에 선택으로 둘 수 있다. 사용자에게 먼저 묻는다

## 꺼내 보는 법

```bash
git clone --depth 1 https://github.com/yihui-dev/awesome-opus5-5-videos "$SCRATCH/opus-videos"   # 스크래치 폴더에
python3 - <<'EOF'
import json
d = json.load(open('opus-videos/data/videos.json'))
#태그·키워드로 거른다. prompt_partial 이 True 면 게시글 문구만 있다
for x in d:
    if 'particles' in x['tech_tags'] and not x['prompt_partial']:
        print(x['slug'], x['post_url'], x['prompt'][:80].replace('\n', ' '))
EOF
```

`prompts/<슬러그>.md` 가 한 개씩 들어 있고, `data/videos.json` 필드는 `slug · author · post_url · category · tech_tags · prompt · prompt_partial`.
