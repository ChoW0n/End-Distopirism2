# 외부 에셋 라이선스 원장 (SPEC-007 §9.8)

반입한 외부 에셋은 전부 여기 적는다. 적지 않은 파일은 쓰지 않는다.

## 반입한 것

| 이름 | 무엇 | 출처 | 라이선스 | 사용처 | 반입일 |
|---|---|---|---|---|---|
| ZzFX 1.3.2 (Micro) | 효과음 합성 코드. 소리 파일 없이 코드로 소리를 만든다 | npm `zzfx` (Frank Force, github.com/KilledByAPixel/ZzFX) | MIT — 저작권 표시와 라이선스 문구를 코드 옆에 남긴다 | 전투 시안 효과음 (다가감·충격·도장) | 2026-09-28 |

## 받을 후보 (이 환경에선 사이트가 막혀 사람이 받는다)

| 팩 | 쓸 곳 | 라이선스 |
|---|---|---|
| Kenney — Impact Sounds | 타격·막기 효과음 | CC0 (팩 안 License.txt 로 확인 후 반입) |
| Kenney — RPG Audio | 검 휘두름·금속음 | CC0 (확인 후 반입) |
| Kenney — Particle Pack | 파편·연기 회색조 입자 → 코드로 물들임 | CC0 (확인 후 반입) |
| Kenney — Smoke Particles | 잔형 물보라·침전 먼지 바탕 | CC0 (확인 후 반입) |

- 받은 팩은 `assets/third_party/<팩 이름>/` 에 두고 팩의 라이선스 파일을 같이 둔다
- 톤은 SPEC-006 §5 에 맞게 회색조로 바꿔 쓰고, 색은 코드가 입힌다
- 라이선스는 받은 날 팩 안의 문서로 다시 확인한다. 이 표의 라이선스는 반입 전 예상값이다

## 쓰지 않는 것

- 림버스 컴퍼니 등 다른 게임에서 추출한 스프라이트·이펙트·UI·효과음 (저작권)
