## 0. 2026-09-21 재작성 경위 — 읽고 넘어갈 것

2026-09-16판 v2.0은 **코인 시스템과 정신력을 제거**한다고 적혀 있었다.
그건 사용자가 결정한 게 아니라 **Claude가 전용기·속성 구조를 옮기면서 임의로 넣은 변경**이었다.
확인 없이 문서에 박혀 있었고, 그 상태로 작업 지시까지 나갔다.

2026-09-21에 되돌렸다. 확정:

| 항목 | 2026-09-16판 (폐기) | 확정 |
|---|---|---|
| 코인 | 제거 | **유지** |
| 정신력 | 제거 | **유지** |
| 합 판정 | 회피 확률(방어레벨×2%)로 교체 | **v1.0 그대로** (코인 굴림 → 피해 비교 → 패자 코인 -1 → 재대결) |
| 교착 | 사라짐 | **v1.0 그대로** (3회 누적 시 합 종료, 정신력 -10) |
| 일방 공격 D-7 | 불명확 | **v1.0 그대로** (자동 승리, 코인 미차감, 정신력 미회복) |
| 레벨차 보너스 | 3단위 ×2로 변경 | **v1.0 그대로** (차이 4 초과 시 floor(차/4)) |

**즉 v2.0에서 실제로 바뀌는 건 §1~§4 네 항목뿐이다.**

## 1. 카드 9종 → 전용기 3종

v1.0 §6의 공용 카드 9종을 폐기하고, **캐릭터마다 자기 전용기 3종**을 갖는다.
카드 풀을 공유하지 않는다. 캐릭터 3명이면 전용기는 총 9종이지만 서로 못 쓴다.

| # | 등급 | 속성 | 프레임 수 | 성격 |
|---|---|---|---|---|
| S1 | 기본 | 공격 | 2장 (준비 → 시전) | 무난한 공격 |
| S2 | 중간 | 방어 | 2장 (준비 → 절정) | 강화 공격 |
| S3 | 강 | 보조 | 3장 (예비 → 시전 → 마무리) | 궁극기 전 준비 기술 |

프레임 수 근거는 프로젝트 문서 `모션시트_제작규칙.md` §3.1. 부족한 후속동작은 이펙트·카메라로 메운다.

### 1.1 수치는 제안값이다 — 시뮬레이터로 확정한다

코인이 살아 있으므로 전용기도 v1.0 카드와 같은 형식(`최소피해` + `코인위력`)을 쓴다.
아래는 **시작 제안값**이고 확정치가 아니다.

| # | 최소피해 | 코인위력 |
|---|---|---|
| S1 | 7 | 1 |
| S2 | 9 | 2 |
| S3 | 11 | 2 |

**확정 조건** (v1.0 §8 밸런싱 원칙 그대로 적용):
- 카드 1장의 피해 변동폭(최대÷최소) **3.0배 이하**
- `npm run sim -- --runs 200` 기준 승률이 한쪽으로 심하게 안 기울 것 (v1.0 실측 아군 53.5%)
- 평균 턴 수가 v1.0(23턴)보다 크게 짧아지지 않을 것 — 속성 누적에 턴이 필요하다

이 조건을 못 맞추면 **수치를 임의로 바꾸지 말고 보고한다.**

### 1.3 시뮬레이터 실측 (2026-09-21, 제안값 그대로)

`npm run sim -- --runs 200` 기준. 수치는 하나도 고치지 않은 상태다.

| 항목 | v1.0 | v2.0 제안값 | 판정 |
|---|---|---|---|
| 아군 승률 | 53.5% | **53.0%** | 통과 |
| 평균 턴 수 | 23.0 | **26.1** (19~44) | 통과 (길어지는 방향) |
| 변동폭 최대 | 2.88배 | **2.11배** (S2) | 통과 |

**속성 누적 속도만 목표에서 벗어난다.**

| 항목 | 목표 (§9-3) | 실측 |
|---|---|---|
| 속성 1개 | 3턴 | **6.4턴** |
| 속성 3개(궁극기) | 9턴 | **13.0턴** |

원인은 카드 수치가 아니라 **D-11 과 D-7 의 조합**이다.
속성은 합 승리로만 오르는데(D-11), 매칭 판정(D-7)에서 실제로 합이 되는 교전이
**전체의 26.8%** 뿐이다. 나머지는 일방 공격이라 속성을 주지 않는다.
합 1건당 속성은 승자 1명에게 1개이므로 캐릭터 1명이 턴당 얻는 기대치가 0.157개가 된다.

전용기 수치를 바꿔도 이 비율은 움직이지 않는다. 조정하려면 D-11(누적 조건) 또는
목표치(§9-3) 중 하나를 다시 정해야 한다. **임의로 바꾸지 않고 결정을 기다린다.**

### 1.2 전용기 효과는 지금 비워 둔다

v1.0 카드 9종의 효과(출혈·독·방어 태세 등)는 상태이상 4종에 묶여 있고,
**상태이상은 v2.0에서 보류 상태**다. 그래서 전용기 3종은 당분간 **순수 피해 + 속성 누적**만 한다.
효과를 임의로 설계해 붙이지 않는다.

## 2. 속성 누적 (신규)

캐릭터마다 **공격·방어·보조 3종 카운터**를 독립적으로 들고 있다. 전용기와 1:1 대응이다.

| 속성 | 올리는 전용기 |
|---|---|
| 공격 | S1 |
| 방어 | S2 |
| 보조 | S3 |

### 2.1 누적 조건 **[D-11]**

```
합 승리 시에만 해당 전용기의 속성 +1
```

- **교착: 미누적** (승리가 아니다)
- **합 패배: 미누적**
- **일방 공격: 미누적** — 겨룬 게 아니다. 정신력 +2를 안 주는 v1.0 §4.7과 같은 논리다.
  일방 공격으로 안전하게 때리는 플레이가 궁극기 축적을 대체하면 안 된다.

> 합 한 판에서 재대결이 여러 번 일어나도 **속성은 합당 1회**다. 코인 차감으로 이어지는
> 개별 교환마다 주면 코인 많은 캐릭터가 궁극기를 훨씬 빨리 채운다.

## 3. 궁극기 (신규)

### 3.1 발동 조건

```
(공격 + 방어 + 보조) ≥ 3
판정 시점 = 턴 종료
효과      = 다음 턴 시작 시 덱에 궁극기 카드 1장 추가
카드 사용 시 = 해당 캐릭터의 3개 속성 전부 0으로 초기화
```

속성 조합은 자유다. 공격 3/0/0도, 1/1/1도 발동한다.

### 3.2 궁극기 카드 수치 — **TBD**

피해량·효과·코인 관여 여부 전부 미정이다. **구현 범위는 여기까지다:**

- 조건 충족 판정 → `ultimateReady` 이벤트
- 다음 턴 덱에 카드 1장 추가
- 카드 사용 시 속성 초기화 → `ultimateUsed` 이벤트

**피해 계산은 구현하지 않는다.** CLAUDE.md "스펙의 TBD 항목이 미결이면 구현하지 말고 먼저 묻는다"에 해당한다.
연출(컷신)을 붙이는 단계에서 같이 정한다.

### 3.3 연출 분리

궁극기 연출은 일반 전용기와 완전히 분리된 컷신이다 (SPEC-002 §7).
**컷신 시작·종료가 피해 판정을 새로 만들지 않는다.** 합 판정 확정 → 연출 이벤트 → 기존 피해 적용 순서.

## 4. 도메인 이벤트 추가

기존 이벤트는 전부 유지한다. 아래만 추가한다.

| `attributeGained` | 합 승리 직후. `{ combatantId, attribute, value }` |

## 5. 바뀌지 않는 것 (확인용)

아래는 v1.0 그대로다. 손대지 않는다.

- 코인 성공 확률 `0.6 × (정신력/100)`, 코인 회복, 코인 차감
- 정신력 증감표 전체 (합 승리 +2, 교착 3회 -10, 턴 종료 +4 상한 30 등)
- 합 판정 3분기(승/패/교착), 교착 3회 누적 종료, 교착 카운터 매칭쌍 단위
- 일방 공격 D-7 규칙 전부
- 레벨차 보너스: 차이 4 초과 시 `floor(차/4)`, 매 합마다 0 초기화
- 캐릭터 스탯 3종, 1:1 매칭, 적 AI 가중 랜덤(§13)
- 상태이상 4종 — **보류 상태 유지.** 비활성으로 두고 재설계는 별도 결정
