## 1. 카드 9종 → 전용기 3종

v1.0 §6의 공용 카드 9종을 폐기하고, **캐릭터마다 자기 전용기 3종**을 갖는다.
카드 풀을 공유하지 않는다. 캐릭터 3명이면 전용기는 총 9종이지만 서로 못 쓴다.

| # | 등급 | 속성 | 프레임 수 | 성격 |
|---|---|---|---|---|
| S1 | 기본 | 공격 | 2장 (준비 → 시전) | 무난한 공격 |
| S2 | 중간 | 방어 | 2장 (준비 → 절정) | 강화 공격 |
| S3 | 강 | 보조 | 3장 (예비 → 시전 → 마무리) | 궁극기 전 준비 기술 |

프레임 수 근거는 프로젝트 문서 `모션시트_제작규칙.md` §3.1. 부족한 후속동작은 이펙트·카메라로 메운다.

### 1.1 수치는 제안값이다 — 시뮬레이터로 확정한다

코인이 살아 있으므로 전용기도 v1.0 카드와 같은 형식(`최소피해` + `코인위력`)을 쓴다.
아래는 **시작 제안값**이고 확정치가 아니다.

| # | 최소피해 | 코인위력 |
|---|---|---|
| S1 | 7 | 1 |
| S2 | 9 | 2 |
| S3 | 11 | 2 |

**확정 조건** (v1.0 §8 밸런싱 원칙 그대로 적용):
- 카드 1장의 피해 변동폭(최대÷최소) **3.0배 이하**
- `npm run sim -- --runs 200` 기준 승률이 한쪽으로 심하게 안 기울 것 (v1.0 실측 아군 53.5%)
- 평균 턴 수가 v1.0(23턴)보다 크게 짧아지지 않을 것 — 속성 누적에 턴이 필요하다

이 조건을 못 맞추면 **수치를 임의로 바꾸지 말고 보고한다.**

### 1.3 시뮬레이터 실측 (2026-09-21)

`npm run sim -- --runs 200`. 전용기 수치는 제안값 그대로 두고, D-11 개정과 궁극기 임시값만 반영한 상태.

| 항목 | v1.0 | 최초안 (D-11 원안) | **확정 (D-11 개정)** | 판정 |
|---|---|---|---|---|
| 아군 승률 | 53.5% | 53.0% | **51.5%** | 통과 |
| 평균 턴 수 | 23.0 | 26.1 | **25.1** (19~42) | 통과 |
| 변동폭 최대 | 2.88배 | 2.11배 | **2.11배** (S2) | 통과 |
| 첫 궁극기 | — | 13.0턴 | **10.6턴** | §9-3 목표(9턴) 근방 |
| 궁극기 사용 | — | **0건** | 전투당 5.0회 | — |
| 속성 1개 | 3턴 목표 | 6.4턴 | **1.7턴** | 임계치 9로 흡수 |

#### 측정 기준 — 이걸 안 맞추면 수치가 어긋난다

"첫 궁극기"는 **캐릭터별 최초 `ultimateReady` 턴의 평균**이다. 200판 · 양측 6명 기준
1200명 중 **1050명(87.5%)** 이 전투 종료 전에 도달하고, 그 평균이 10.6턴이다.

같은 데이터를 **전투 단위**(판마다 누군가 처음 도달한 턴)로 재면 **9.3턴**이 나온다.
200판 전부에서 발생하므로 이 값이 더 짧다. 둘 다 맞는 수치이고 세는 단위가 다를 뿐이다.
**§9-3 목표와 비교할 때는 캐릭터 단위(10.6턴)를 쓴다** — 목표 문장이 "캐릭터 한 명이
3턴에 1개, 9턴에 3개"이기 때문이다.

최초안이 0건이었던 이유는 궁극기 수치가 TBD라 AI가 고르지 않았기 때문이다. 즉 그때의
승률·턴 수는 **궁극기가 없는 게임의 수치**였다. 지금 수치는 궁극기가 실제로 터지는 상태다.

교전 중 합의 비율은 **26.3%**로 D-11 개정 전후가 같다. 이 값은 D-7 매칭 구조가 정하는 것이라
카드 수치로는 움직이지 않는다.

### 1.2 전용기 효과는 지금 비워 둔다

v1.0 카드 9종의 효과(출혈·독·방어 태세 등)는 상태이상 4종에 묶여 있고,
**상태이상은 v2.0에서 보류 상태**다. 그래서 전용기 3종은 당분간 **순수 피해 + 속성 누적**만 한다.
효과를 임의로 설계해 붙이지 않는다.

## 2. 속성 누적 (신규)

캐릭터마다 **공격·방어·보조 3종 카운터**를 독립적으로 들고 있다. 전용기와 1:1 대응이다.

| 속성 | 올리는 전용기 |
|---|---|
| 공격 | S1 |
| 방어 | S2 |
| 보조 | S3 |

### 2.1 누적 조건 **[D-11 · 2026-09-21 개정]**

```
피해를 넣은 쪽이 해당 전용기의 속성 +1
= 합 승리 + 일방 공격
```

- **교착: 미누적** (아무도 피해를 못 넣었다)
- **합 패배: 미누적**
- **일방 공격: 누적** ← 개정 지점

> **개정 이유.** 최초안은 "합 승리 시에만"이었다. 정신력 +2를 일방 공격에 안 주는 v1.0 §4.7과
> 같은 논리였는데, 실측에서 **전체 교전의 26.8%만 합이고 나머지 73%가 일방 공격**이라
> 궁극기가 13턴에 한 번꼴로 밀렸다(목표 9턴). 일방 공격을 빼면 누적 속도를 전용기 수치로
> 조절할 수 없다 — 이 비율은 D-7 매칭 구조가 정하는 값이라 카드를 어떻게 바꿔도 안 움직인다.
> 정신력과 달리 속성은 "겨루기 보상"이 아니라 **행동 축적**으로 재정의한다.

> 합 한 판에서 재대결이 여러 번 일어나도 **속성은 합당 1회**다. 코인 차감으로 이어지는
> 개별 교환마다 주면 코인 많은 캐릭터가 궁극기를 훨씬 빨리 채운다.

## 3. 궁극기 (신규)

### 3.1 발동 조건

```
(공격 + 방어 + 보조) ≥ ultimateThreshold
판정 시점 = 턴 종료
효과      = 다음 턴 시작 시 덱에 궁극기 카드 1장 추가
카드 사용 시 = 해당 캐릭터의 3개 속성 전부 0으로 초기화 + 덱에서 제거
```

속성 조합은 자유다. 한 속성에 몰려도, 고르게 퍼져도 발동한다.

**임계치는 `battle-data.json`의 `ultimateThreshold`가 정한다. 현재 9.**
D-11 개정으로 누적이 턴당 약 0.6개로 빨라져서, 최초안의 3을 그대로 두면 3턴마다 궁극기가 나온다.
**§9-3의 "9턴에 궁극기 1회" 목표를 유지하려고 3 → 9로 올렸다.**
실측 첫 발동 10.6턴 (캐릭터별 최초 기준, §1.3 측정 기준 참조).

### 3.2 궁극기 카드 수치 — **임시값 (확정 아님)**

| 항목 | 값 | 비고 |
|---|---|---|
| 최소피해 | 18 | S3(11)의 약 1.6배 |
| 코인위력 | 3 | 전용기 최대(2)보다 1 높다 |
| 속성 | 없음 | 궁극기는 속성을 올리지 않는다. 쓰면 0으로 초기화된다 |
| 효과 | 없음 | 상태이상 보류 상태 (D-14와 동일) |

**왜 임시값이라도 넣었나.** 처음엔 TBD로 두고 AI가 고르지 않게 했는데, 그 상태로 잰 밸런스는
**궁극기가 한 번도 안 터진 수치**였다(200판에서 사용 0건). 궁극기를 포함한 밸런스를 재려면
숫자가 있어야 한다. 확정치는 컷신 연출을 붙일 때 다시 잡는다.

### 3.3 연출 분리

궁극기 연출은 일반 전용기와 완전히 분리된 컷신이다 (SPEC-002 §7).
**컷신 시작·종료가 피해 판정을 새로 만들지 않는다.** 합 판정 확정 → 연출 이벤트 → 기존 피해 적용 순서.

## 5. 바뀌지 않는 것 (확인용)

아래는 v1.0 그대로다. 손대지 않는다.

- 코인 성공 확률 `0.6 × (정신력/100)`, 코인 회복, 코인 차감
- 정신력 증감표 전체 (합 승리 +2, 교착 3회 -10, 턴 종료 +4 상한 30 등)
- 합 판정 3분기(승/패/교착), 교착 3회 누적 종료, 교착 카운터 매칭쌍 단위
- 일방 공격 D-7 규칙 전부
- 레벨차 보너스: 차이 4 초과 시 `floor(차/4)`, 매 합마다 0 초기화
- 캐릭터 스탯 3종, 1:1 매칭, 적 AI 가중 랜덤(§13)
- 상태이상 4종 — **보류 상태 유지.** 비활성으로 두고 재설계는 별도 결정
