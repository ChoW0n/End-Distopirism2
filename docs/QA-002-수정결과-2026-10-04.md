## 전투 수명 기준

- 상태는 부여 즉시 적용된다. 같은 턴의 후속 교전에도 효력이 있다.
- 지속 1턴은 다음 턴의 판정까지 유지되고 그 턴 종료에 만료된다.
- 출혈 3턴은 다음 세 번의 턴 시작에 정확히 3회 발동한다. 중첩마다 부여 시점을 따로 지킨다.
- 이미 있던 긴 상태에 짧은 상태를 덧걸어 수명이 늘어나지는 않는다.
- 전투 시작 전부터 있던 상태는 첫 턴 종료부터 감소한다.

회귀 테스트는 실제 `Battle.startTurn → submitOrders → resolve → endTurn`을 통과한다. 순수 도메인에 DOM·three.js 의존성을 추가하지 않았다.

## 검증 근거

- 최종 타입 검사 통과. 자동 검사 **510 통과 / 0 실패 / 0 건너뜀**.

- 이면 회귀는 수정 전 `statusExpired`의 조기 발생으로 실패했고 수정 후 통과했다.
- 기존 QA의 원본 브라우저에서도 모달 Enter, 503 로딩 고정, 늦은 스킬 선택 덮어쓰기를 재현했다.
- UI는 10월 1일 승인 v4 원본에서 누락 55장을 복구했다. 기존 45장 포함 총 100장의 원본 SHA-256·이미지 크기가 일치한다. 그림을 생성하거나 다른 상태로 대체하지 않았다.
- 현재 카일 대 잔형 200시드가 모두 종료됐다. 시작·해결·종료 3,244단계에서 HP/SP가 유한수이고 범위 안에 있었다. 4~10턴, 평균 5.74턴. 밸런스 승인 표본으로 해석하지 않는다.
- Chromium 데스크톱·모바일 터치 에뮬레이션 회귀 31항목 통과. 실제 기기의 Safari 검증은 아니다.
- 위 200판에서 자연 혼란은 발생하지 않았다. 혼란 지속·확률은 별도 낮은 정신력 회귀로 확인한다.
- 직접 시드 1: 물금→이면→잔향→미명으로 4턴 승리. 자동 시드 2는 8턴 패배, 시드 3은 5턴 승리.
- 정상 직접·자동 전투와 VFX에서 HTTP 404·페이지 실행 오류는 0개다. 의도한 503 실패 주입은 별도 집계했다.
- 도움말·메뉴 포커스 순환과 복원, 뒤쪽 버튼 클릭·숫자 단축키 차단을 확인했다. 카드 버튼 포커스에서 숫자 전환·Enter 선택·교전 시작도 유지된다.
- S2·S3의 궤도 +60°·높이 20°에서도 곡면과 효과가 남고 지면 아래 완전 소실은 없었다. S3 측면은 얇게 보이므로 측면 가독성은 후속 아트 검수에 남긴다.
- 공간형 투영 검사는 실제 CameraRig의 대기·교전·근접 카메라에서 1920×1080 환산 꼭짓점 오차 0.01px 미만을 확인한다. 최종 화면 전체의 픽셀 일치나 원본 붓결 복제를 뜻하지 않는다.

## 잔여 항목과 다음 작업

S1의 기존 셰이더는 질감 띠와 색 매핑을 쓰므로 원본 15장과 밝기·붓결·입자가 다르다. 이번 작업에서 원본 일치 아트 승인이나 본편 적용 승인을 내리지 않는다. 원본 컬러 효과 레이어를 기준으로 질감 보존을 검수하는 작업이 다음 순서다.

실제 iPhone/Safari, 청취 기반 사운드 평가, 장시간 GPU·메모리·발열은 이번 수정의 통과 범위가 아니다. Chromium 모바일 에뮬레이션과 실제 기기 검증을 혼동하지 않는다.

새 채팅에서는 이 문서와 최신 소스 브랜치를 먼저 읽고 **S1 원본 질감 보존 및 공간형 연출 아트 검수**로 이어간다. 이미 고친 입력·로딩·상태 수명을 다시 구현하지 않는다.
